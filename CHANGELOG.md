# Changelog

## 1.0.0 - 2026-10-07

First public release of iPhone Organizer for Windows x64.

- Visual Home Screen organization with real app icons, folders, dock, and wallpaper.
- Equal six-row page previews and separate expanded-folder views.
- Draft movement, folder creation and renaming, undo, and protected page one/dock.
- Keep/Delete sorting with K/D/Z shortcuts, saved progress, and Identifier-based exports.
- Apple com.apple apps excluded from sorting and deletion.
- Reviewed layout and deletion plans, original-layout backups, stale-state checks, and device verification.
- Shared local engine with 18 MCP tools and a stdio bridge.
- Self-contained portable runtime and retained component licenses.

Validation: 18 simulated-engine regression tests; live USB reads, icon and wallpaper retrieval, MCP communication, and an unchanged-layout verification. Compatibility has been checked on one iPhone running iOS 27.0; other versions require validation.
