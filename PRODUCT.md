# iPhone Organizer

A portable Windows application for organizing a trusted iPhone connected over USB. The user arranges live Home Screen pages, dock, and folders visually or through an MCP assistant. Changes are staged, explicitly reviewed, backed up, and verified against the phone.

The companion app sorter records Keep/Delete choices by unique Identifier, supports keyboard shortcuts and undo, saves progress, and exports separate lists. The com.apple namespace is excluded from sorting and deletion; those icons remain available in layout organization.

The UI and MCP share one serialized local device engine. Apple device support and a trusted phone are required. No app data restoration is promised. Preserve original icon records and user changes, page one and dock protections, and stale-plan checks.

Audience: a person managing their own iPhone on a Windows desktop, often with an assistant. Primary tasks are examining app placement, grouping and moving apps, making retention decisions, and reviewing exact changes before applying.
